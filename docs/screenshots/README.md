# Screenshots

Current demo captures use Playwright/Chromium against an isolated `APP_MODE=demo` instance with temporary data/private directories, no `.env`, and the web terminal disabled. Wait for the seeded Servers workspace and fonts to load before capturing full-page screenshots.

- `overview.png` - Servers workspace at a 1440 × 1000 desktop viewport.
- `mobile.png` - Servers workspace at a 390 × 844 mobile viewport.

Host names and metrics are built-in simulated demo data, not live telemetry.

Screenshots must not include real hostnames, IP addresses, secrets, passwords, private keys, or public key material.
